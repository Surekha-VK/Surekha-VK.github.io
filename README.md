## 🛠️ Tech Stack

- **HTML5:** Semantic markup, accessibility attributes (`aria-*`), SEO-friendly metadata.
- **CSS3:** Custom CSS properties (variables), Flexbox, CSS Grid, media queries, smooth animations, dark/light theme variables.
- **JavaScript (Vanilla ES6+):** Dark/Light mode switcher with `localStorage`, responsive mobile navigation menu, dynamic scroll tracking for active link highlights, back-to-top floating button.
- **Hosting & Deployment:** GitHub Pages (User Pages site).
